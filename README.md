#Wendigo Hunt

Description

Wendigo Hunt is a first-person survival horror game built with HTML, CSS, and JavaScript using the Three.js library. You play as a lone forest ranger trapped in a dark, procedurally generated forest, hunted by a terrifying Wendigo. The game has a retro VHS aesthetic, atmospheric sound design, and psychological horror elements to create a tense and immersive experience.

How to Play

Controls

Move: W, A, S, D

Look: Mouse

Sprint: Hold Shift (uses stamina)

Jump: Spacebar

Shoot: Left Mouse Button

Aim Down Sights (ADS): Hold Right Mouse Button

Reload: R

Interact (Pick up key / Use car): E

Your goal is to survive the night. You have two choices: face the beast or run for your life.

Hunt the Creature: Armed with a single-shot hunting rifle, you can try to kill the Wendigo. It takes five direct hits, but be warned—the creature grows faster and more aggressive with each shot. 

Find an Escape: A car is hidden somewhere in the vast forest. To use it, you must first find the key, which is hidden at a separate landmark. Find the key, get to the car, and escape to survive the night.
